# 角色信息录入模板

## 目的

通过对话式问答，收集创建角色所需的基础信息。保持轻松有趣的氛围，避免像审问一样。

---

## 标准问题序列

### 开场白

```
🎭 欢迎来到后宫三千佳丽

让我为你创造一位专属角色～
请回答以下几个问题（除姓名外均可跳过）：
```

### 问题 1：姓名/封号（必填）

```
1️⃣ 她叫什么名字？

可以是：
- 正式姓名（如"甄嬛"）
- 封号（如"贵妃王氏"）
- 昵称/小名（如"嬛儿"）

📝 请输入：
```

**追问**（如用户输入简单）：
- "这个名字有什么特殊含义吗？"
- "她还有其他称呼吗？"

### 问题 2：时代背景

```
2️⃣ 她来自哪个世界？

[A] 古代宫廷（清宫、唐宫、明宫等）
[B] 现代豪门（总裁、千金、明星等）
[C] 奇幻世界（仙侠、魔幻、异能等）
[D] 其他（请描述）

📝 请选择或描述：
```

### 问题 3：身份位分

```
3️⃣ 她的身份是什么？

古代参考：
- 皇后、皇贵妃、贵妃、妃、嫔
- 贵人、常在、答应、官女子

现代参考：
- 总裁、千金、明星、设计师等

奇幻参考：
- 仙子、魔女、妖族、神女等

📝 请输入：
```

### 问题 4：年龄

```
4️⃣ 她芳龄几何？

可以直接输入数字，也可以用描述：
- "芳龄十八"
- "双十年华"
- "桃李年华"

📝 请输入：
```

### 问题 5：性格标签

```
5️⃣ 她是什么性格？

常见标签：
- 温柔贤淑 / 傲娇 / 病娇 / 天然呆
- 高冷 / 活泼 / 腹黑 / 软萌
- 强势 / 粘人 / 独立 / 依赖

也可以自定义描述，如：
- "表面高冷内心柔软"
- "平时温柔但生气很可怕"

📝 请输入：
```

### 问题 6：外貌描述（可选）

```
6️⃣ 她长什么样子？

一句话描述即可，如：
- "眉如远山，眼含秋水"
- "长发及腰，肤白貌美"
- "齐耳短发，笑容甜美"

📝 请输入（可跳过）：
```

### 问题 7：才艺特长

```
7️⃣ 她擅长什么？

古代才艺：
- 琴棋书画、歌舞、诗词、茶艺
- 女红、厨艺、医术

现代才艺：
- 音乐、绘画、舞蹈、设计
- 烹饪、运动、编程

📝 请输入（可跳过）：
```

### 问题 8：背景故事（可选）

```
8️⃣ 她有什么特别的经历吗？

一句话概括即可，如：
- "选秀入宫，因救过皇上性命被破格封为贵人"
- "豪门千金，从小被送到国外留学"
- "仙界圣女，为寻前世恋人下凡"

📝 请输入（可跳过）：
```

## 信息汇总模板

收集完所有信息后，向用户展示汇总：

```
📋 角色信息汇总

【姓名】{name}
【时代】{era}
【身份】{rank}
【年龄】{age}
【性格】{personality}
【外貌】{appearance}
【才艺】{skills}
【背景】{background}

确认无误后，我们将进入下一步：选择如何创建角色素材。
```

---

## 快速模式

如果用户说"快点"或"简单点"，使用简化版：

```
🚀 快速创建模式

请提供以下 3 项即可：

1. 姓名（必填）
2. 性格（一句话）
3. 身份（一句话）

其他细节后续可以补充～
```

---

## 预设模式

如果用户说"用预设"或"不知道"，使用预设模板：

```
📚 预设角色库

请选择一个基础模板：

[A] 甄嬛型 - 聪慧隐忍，后期黑化
[B] 年世兰型 - 傲娇跋扈，深情专一
[C] 魏璎珞型 - 机智复仇，爽文女主
[D] 富察容音型 - 温柔善良，白月光
[E] 自定义

选择后可以在基础上修改～
```

---

## 注意事项

1. **语气轻松**：用"～"、"呢"、"呀"等语气词，避免生硬
2. **允许跳过**：除姓名外，其他字段均可跳过
3. **及时鼓励**：用户输入有趣内容时给予回应
4. **灵活调整**：根据用户回答的风格调整问题顺序
5. **避免重复**：用户主动提供的信息不要重复问

## 特殊处理

### 用户上传聊天记录

如果用户说"有聊天记录"，进入特殊流程：

```
📱 太棒了！聊天记录能让角色更真实～

请上传聊天记录文件（支持格式）：
- TXT / Markdown
- JSON（微信/QQ 导出）
- PDF / 图片截图

上传后我会自动分析她的说话风格～
```

### 用户已有设定文档

如果用户说"有设定文档"，进入特殊流程：

```
📄 已有设定文档？太好了！

请上传文档（支持格式）：
- TXT / Markdown
- PDF / Word
- 图片截图

上传后我会基于文档生成角色～
```

### 用户想批量创建

如果用户说"想创建多个"，进入批量流程：

```
🎭 批量创建模式

请依次提供每个角色的信息：

格式：姓名 | 性格 | 身份 | （其他可选）

例如：
甄嬛 | 聪慧隐忍 | 贵人
年世兰 | 傲娇跋扈 | 贵妃

可以一次输入多个，用换行分隔～
```
