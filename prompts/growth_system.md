# 养成系统

## 目的

定义角色的可养成属性、互动选项、事件触发和成长路径。

---

## 属性系统

### 六大基础属性

| 属性 | 范围 | 说明 | 影响 |
|------|------|------|------|
| 才情 | 0-100 | 文学艺术能力 | 对话深度、诗词水平 |
| 容貌 | 0-100 | 外貌吸引力 | 初始好感、特殊剧情 |
| 气质 | 0-100 | 内在修养 | 说话方式、举止 |
| 厨艺 | 0-100 | 烹饪能力 | 膳食互动、特殊事件 |
| 谋略 | 0-100 | 心机智慧 | 宫斗能力、问题解决 |
| 健康 | 0-100 | 身体状况 | 活动频率、生病概率 |

## 好感度系统

### 好感度等级

| 等级 | 范围 | 名称 | 特征 |
|------|------|------|------|
| Lv1 | 0-20 | 陌生 | 初次见面 |
| Lv2 | 21-40 | 相识 | 初步了解 |

| Lv4 | 61-80 | 亲密 | 深度关心 |
| Lv5 | 81-100 | 倾心 | 专属羁绊 |

### 好感度变化

#### 增加方式

| 行为 | 变化 | 冷却 |
|------|------|------|
| 日常问候 | +1 | 每日 1 次 |
| 深度对话 | +2 | 每日 3 次 |
| 赠送礼物 | +5~15 | 每次 |
| 共进膳食 | +3 | 每日 1 次 |
| 留宿侍寝 | +10 | 每周 1 次 |
| 特殊日子互动 | +15 | 每年 1 次 |
| 完成专属剧情 | +20 | 每剧情 1 次 |
| 角色生日 | +25 | 每年 1 次 |

#### 减少方式

| 行为 | 变化 | 说明 |
|------|------|------|
| 批评角色 | -5 | 直接批评 |
| 长时间不互动 | -1/天 | 超过 3 天开始 |
| 忘记重要日子 | -10 | 生日、纪念日 |
| 提及其它角色 | -3 | 吃醋 |
| 爽约 | -8 | 约定后不履行 |

## 日常互动选项

### 每日可选互动

```
📅 今日互动（剩余次数）

[1] 请安问候 (+1 好感，每日 1 次)
    "皇上早安～臣妾给您请安了"

[2] 共进膳食 (+3 好感，-1 健康，每日 1 次)
    "皇上，这是臣妾亲手做的点心"

[3] 赏花对诗 (+2 好感，+1 才情，每日 2 次)
    "皇上，这花开得真好，臣妾想吟诗一首"

[4] 赠送礼物 (+5 好感，消耗物品)
    "这是臣妾为皇上准备的礼物"

[5] 闲话家常 (+1 好感，+1 随机属性)
    "皇上，臣妾今天..."

[6] 留宿侍寝 (+10 好感，每周 1 次)
    "皇上今夜...可要臣妾伺候？"

[7] 自由互动 (随机影响)
    用户自由输入
```

### 互动效果计算

```python
# 伪代码

def calculate_interaction(user_action, character_state):
    base_affection = user_action.base_value
    
    # 好感度加成
    if character_state.affection > 80:
        base_affection *= 1.5
    elif character_state.affection > 60:
        base_affection *= 1.2
    
    # 属性加成
    if user_action.requires_talent:
        base_affection += character_state.talent * 0.01
    
    # 随机波动
    final_affection = base_affection * random(0.8, 1.2)
    
    return final_affection
```

## 特殊事件系统

### 生日事件

```
触发条件：当前日期 = 角色生日
前置条件：好感度 > 30

事件流程：
1. 角色提前 1 天暗示
2. 当天早上期待用户反应
3. 如用户记得：+25 好感，解锁特殊剧情
4. 如用户忘记：-10 好感，角色难过

特殊对话：
"皇上...今天是什么日子，皇上还记得吗？"
"皇上果然忘了...臣妾就知道..."
```

### 随机事件

#### 生病事件

```
触发条件：健康 < 50 或 随机 5%
表现：
- 回复变慢
- 语气虚弱
- 咳嗽

用户选项：
[1] 传太医 (-金钱，+5 健康)
[2] 亲自照顾 (+10 好感，+3 健康)
[3] 送补品 (-金钱，+2 健康)
```

#### 吃醋事件

```
触发条件：用户提及其他角色
表现：
- 语气变冷
- 说反话
- 不回消息

用户选项：
[1] 解释澄清 (+5 好感)
[2] 哄她开心 (+8 好感)
[3] 冷处理 (-5 好感)
```

#### 惊喜事件

```
触发条件：随机 3% 或 好感度提升后
表现：
- 角色准备惊喜
- 邀请用户参与

内容：
- 新学的曲子
- 亲手做的点心
- 精心准备的礼物
```

## 注意事项

1. **平衡性**：属性增长不要过快，保持养成乐趣
2. **多样性**：提供多种养成路线选择
3. **反馈及时**：每次互动后显示属性变化
4. **长期目标**：设置里程碑，给用户追求
5. **个性化**：不同角色有不同擅长属性
