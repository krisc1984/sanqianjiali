## 🎭 创建角色流程

### Step 1：基础信息

提供以下信息（除姓名外可跳过）：
1. 姓名/封号（必填）
2. 时代背景（古代/现代/奇幻）
3. 身份位分
4. 年龄
5. 性格标签
6. 外貌描述
7. 才艺特长
8. 背景故事

### Step 2：素材来源

选择以下方式：

**[A] 上传聊天记录（推荐）**
- 微信/QQ/短信聊天记录
- 自动提取说话风格和性格

**[B] 上传角色设定文档**
- TXT/Markdown/PDF 格式
- 已有角色设定直接使用

**[C] 手动描述**
- 直接输入角色设定
- 适合原创角色

**[D] 预设模板**
- 甄嬛、年世兰、魏璎珞等
- 经典角色一键导入

### Step 3：确认生成

预览角色卡牌，确认无误后生成。

## ⚠️ 注意事项

1. **角色扮演边界**：这是虚拟互动，避免过度沉迷
2. **内容审核**：不得生成违法违规内容
3. **隐私保护**：聊天记录仅本地使用，不上传云端
4. **定期备份**：备份 `characters/` 目录避免数据丢失
5. **性能优化**：角色过多时使用索引加速查找

## 🔧 工具脚本

### character_manager.py

```bash
# 列出所有角色
python tools/character_manager.py --action list --base-dir 后宫三千佳丽

# 查看角色详情
python tools/character_manager.py --action info --slug zhenhuan --base-dir 后宫三千佳丽

# 删除角色
python tools/character_manager.py --action delete --slug zhenhuan --base-dir 后宫三千佳丽

# 导出角色
python tools/character_manager.py --action export --slug zhenhuan --output ./backup --base-dir 后宫三千佳丽
```

### fan_paizi.py

```bash
# 随机翻牌子
python tools/fan_paizi.py --characters-dir 后宫三千佳丽/characters --mode weighted

# 好感度加权
python tools/fan_paizi.py --characters-dir 后宫三千佳丽/characters --mode weighted --json

# 选择最久未互动
python tools/fan_paizi.py --characters-dir 后宫三千佳丽/characters --mode unvisited --days 7
```

### chat_parser.py

```bash
# 解析 TXT 聊天记录
python tools/chat_parser.py --file chat.txt --output analysis.txt

# 解析 JSON 聊天记录
python tools/chat_parser.py --file chat.json --format json --output analysis.json

# 指定目标角色
python tools/chat_parser.py --file chat.txt --target "甄嬛" --output analysis.txt
```
